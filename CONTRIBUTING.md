# 🛠️ TalentBD Development Setup Guide

Welcome! Follow these steps to get the TalentBD 2026 Ecosystem running on your local machine.

## 1. Prerequisites

- **Node.js**: v18.x or higher
- **MongoDB Atlas**: A cloud database cluster
- **Git**: For version control

## 2. Local Installation

### Clone the Repo

```bash
git clone [https://github.com/sheam274/talent-bd.git](https://github.com/sheam274/talent-bd.git)
cd talent-bd
```
